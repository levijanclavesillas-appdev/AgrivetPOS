Set up Chachi Agrivet POS

Five steps. Nothing is saved until the last one.

    1 · Your store

    2 · Tax

    This sets how prices are treated on every sale. Only the owner can change it later, and the change is recorded.

    3 · Owner account

    The first account. It can do everything, including creating the rest.

    4 · Recovery code

    This application runs offline, so there is no "forgot password" email. This code is the only way back into the owner account if the password is lost.

    It is shown once, on the last screen of this wizard, and cannot be shown again. Write it down and keep it somewhere away from the computer.

    5 · Backup folder

    Backups run at every shift close and once a day. This folder must be outside the application's own folder — ideally another drive — so a backup survives losing the computer's disk.

    The folder is created if it does not exist, and is tested by writing a file to it before setup finishes.

    Setup complete

    Write this recovery code down now. It will not be shown again.
